How to Start

Saturday Path (Fastest)

  1. 1. RSVP for Friday Zoom (text 813-445-8889)
  2. 2. Attend Zoom — ask questions, see the schedule
  3. 3. Pay online before Saturday ($99/class)
  4. 4. Arrive Saturday 8am (or 12:30 for AI class)
  5. 5. Return next Saturday for Parts 3 & 4 → Graduate

SUFS Scholarship Path

  • Confirm scholarship type (FES-UA/PEP/FES-EO)
  • Contact scholarships@missionaviationacademy.org
  • Select SUFS-eligible program from EMA
  • Funds deposited 2–5 business days
  • No out-of-pocket cost for eligible families
  • Cycles: July · Oct · Jan · April

FES-UA: up to $22,000/yr · PEP: up to $10,000/yr
